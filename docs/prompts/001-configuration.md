### Objetivo del MVP

Construiremos un pequeño sistema de blogs donde:

* Un usuario puede **registrarse/iniciar sesión**.
* Puede ver **todos los posts públicos**.
* Puede ver específicamente **sus propios posts**.
* Puede **crear, consultar, editar y eliminar sus posts**.
* Puede consultar los posts de otros usuarios, pero **no modificarlos ni eliminarlos**.
* Laravel será quien controle la **autenticación, autorización, relaciones, validaciones, rutas, controladores, modelos y vistas**.

### Cómo voy a enseñártelo

No te voy a entregar todo el código de una vez.

Vamos a trabajar por **secuencia lógica**, por ejemplo:

> **Necesitamos X → para conseguir X necesitamos Y → Laravel resuelve Y mediante Z → lo implementamos → lo probamos → entendemos qué ocurrió → continuamos.**

En cada etapa te explicaré:

1. **Qué vamos a construir.**
2. **Por qué lo necesitamos.**
3. **Qué concepto de Laravel estamos aprendiendo.**
4. **Qué archivos vamos a tocar y por qué.**
5. **Qué código debes escribir.**
6. **Cómo probarlo.**
7. **Qué debería ocurrir.**
